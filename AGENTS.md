# CECREH manuscript tracker

This repository contains the static application and **synthetic demonstration data**. Confidential records live outside this repository until the organization owner verifies the exact source and hosting audiences.

- Never edit CECREH/grants for this project.
- Never put real manuscript titles, authors, draft URLs, reviewer documents, raw research data, or credentials into the demo, tests, screenshots, or CI artifacts.
- Default every new remote repository to private. Private source does not make GitHub Pages private. No deployment is configured here.
- Preserve stable manuscript IDs, canonical-link history, and submission history. Topic similarity is not evidence that two records are the same paper.
- Unknown values remain null or unconfirmed. Agreed and proposed dates must stay separate.
- Update the schema, validator, field dictionary, and tests together. Run npm run check after functional changes.
- Do not add analytics, browser persistence, email ingestion, or a database.
- Public publication or any broader audience requires explicit approval. Any PR must be a draft.
